# MKR-CAT — Qualification future

Périmètre d'étude : Control Expert PIDFF, PI_B, PIFINT sur Schneider, PID_Compact, PID_3Step, PID_Temp sur Siemens, PID et PIDE sur Rockwell. Statut de tous les candidats : non étudié. Chaque fiche doit référencer nom exact, environnement, CPU, firmware, version, source officielle, équation, unités, limites, modes, option de conversion et preuve du statut. Les statuts progressent de non étudié à documenté, vérifié en environnement puis qualifié sur matériel.
